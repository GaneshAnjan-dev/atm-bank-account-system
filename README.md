# ATM & Bank Account System (Console, Java + MySQL)

- Tech: Core Java, JDBC, MySQL
- Features: Admin panel, user ATM login, balance check, deposit, withdraw, transaction history
- How to run:
  1. Import project into Eclipse
  2. Set up MySQL database `atm_system` with `users`, `accounts`, `transactions` tables
  3. Update DB credentials in `DBConnection.java`
  4. Run `LoginMenu` main method
